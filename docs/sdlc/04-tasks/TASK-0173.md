# TASK-0173: Sales Lead Console

## Outcome

Give platform admins a bounded lead list with status transitions and follow-up
notes, without exposing tenant private customer data or payment secrets.

## Acceptance criteria

1. `GET /api/platform/leads` lists leads with filters (status, kind, source)
   for `platform_admin` only.
2. `PATCH /api/platform/leads/{id}` updates lifecycle status among the approved
   set and records actor + timestamp.
3. Notes can be appended; note bodies are audit-logged and never include payment
   secrets by design (no payment fields on lead model).
4. Platform admin UI under `/admin/leads` shows list + detail drawer with
   status and notes.
5. `tenant_admin` and unauthenticated callers receive 401/403.

## Verification

```bash
go test ./cmd/server ./internal/store -count=1
# platform admin can list/update; tenant token is forbidden
git diff --check
```
