# TASK-0159: Credential vault (ON HOLD)

## Outcome

Customer Claude API keys are encrypted at rest and only masked connection
metadata is returned to the browser.

## Acceptance criteria

1. Save and rotate encrypts the key with `TENANT_SECRET_ENCRYPTION_KEY`.
2. Reads expose provider, mode, status, expiry, version, and last four only.
3. Revoke removes the connection and expired credentials fail closed.
4. Unsupported providers and subscription mode return stable conflict errors.

## Verification

Store encryption/decryption paths and public connection redaction are covered
by automated tests; live database verification requires local infrastructure.
