# TASK-0203: Mic/Speaker Device Settings for Voice

## Done notes

Implemented in SPRINT-056 worktree.

## Outcome

Callers can list and select microphone (input) and speaker (output) devices;
voice capture/playback uses the selection. Preferences persist for the session
(and optionally localStorage).

## Acceptance criteria

1. Audio settings UI exposes mic list and speaker list (when browser allows).
2. Selecting a mic applies to the next (or active) voice capture path.
3. Selecting a speaker applies to playback when `setSinkId` is supported;
   otherwise default output with non-technical note.
4. Last mic/speaker device ids stored in sessionStorage and/or localStorage
   under `monti_jarvis:` prefix keys.
5. Permission denied / empty device list shows clear EN/TH-friendly messaging
   (no raw DOMException dumps).
6. Settings do not break chat-only flow (audio optional until voice starts).

## Implementation notes

- Browser: `navigator.mediaDevices.enumerateDevices`, `getUserMedia`
- Wire into `apps/customer-web/src/lib/voice/gemini.ts` (and LiveKit if used)
- Prefer client-only; no server device registry
