# TASK-0214: Friendly Call Controls, Transcript, and Composer UX

## Outcome

Call controls, transcript, and message/hold-to-talk composer are easier to scan
and use during active calls on desktop and mobile.

## Done Notes

Added the central avatar stage, waveform/listening pill, speaker/mute/end/keypad
/more controls, hold-to-talk affordance, and refreshed transcript/composer
styling while preserving the existing chat/call handlers. Speaker now toggles
the live playback gain, microphone mute toggles the active media track, and the
keypad opens a keyboard-editable numeric dialog that writes into the message
composer.

## Acceptance Criteria

1. Speaker, mute, end call, keypad, more, new session, hold-to-talk, send, and
   listening states have clear visual hierarchy and accessible labels.
2. End call remains visually distinct and difficult to confuse with secondary
   controls.
3. Transcript bubbles show AI/customer identity, timestamp where available, and
   readable line lengths.
4. Composer supports the existing text-send behavior and does not overlap call
   controls or transcript.
5. Active, disabled, loading, and error states do not shift layout.
6. EN/TH/JA labels fit or wrap cleanly in controls and transcript chrome.
7. Speaker and microphone controls change the real call media state and expose
   their pressed state; keypad supports pointer and physical keyboard entry.

## Notes

- Keypad is text-composer input, not telephony DTMF. More remains an avatar
  action menu until additional call actions are defined.
- Keep current voice/text state machine intact.
