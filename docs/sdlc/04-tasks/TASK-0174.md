# TASK-0174: Funnel Events and Verification

## Outcome

Record coarse funnel events for product-web conversion measurement and close
the sprint verification gate with automated tests plus a manual smoke path.

## Acceptance criteria

1. `POST /api/public/funnel/events` accepts allowlisted event names
   (`page_view`, `cta_click`, `demo_start`, `lead_submit`, `register_start`)
   with campaign/ref context and no free-form PII body.
2. Events are rate-limited and stored or aggregated without conversation text.
3. Automated tests cover lead dedupe, public packages, redirect allowlist, and
   funnel event validation.
4. Manual smoke: product home → pricing → contact lead → register CTA → demo CTA.
5. `make test` and `make build` (including product-web) pass.

## Verification

```bash
make product-web
make test
make build
git diff --check
```
