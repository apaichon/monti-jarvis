# TASK-0200: Tenant Call-Center Statistics Topic API

## Outcome

The tenant statistics endpoint returns topic aggregates and accepts an optional
topic filter while preserving the existing S25 response contract.

## Acceptance Criteria

1. `GET /api/tenant/call-center/statistics` includes `by_topic` rows with
   `topic`, `label`, `completed`, `total_duration_seconds`, and
   `average_duration_seconds`.
2. Optional query `topic={value}` filters totals and existing breakdowns to that
   topic.
3. Invalid topic filters return `400 validation_error`.
4. Tenant ID is derived only from auth context; no tenant selector is accepted.
5. Analytics-unavailable and quota-unavailable error behavior stays compatible
   with S25.

## Notes

- Topic labels may be server-provided for common values, but topic codes remain
  stable lowercase analytics dimensions.

## Implementation

- `GET /api/tenant/call-center/statistics` returns top-level `topic` and
  `by_topic` rows.
- Optional `topic=` query filters totals, avatar, channel, and topic aggregates.
- Invalid topic filters return `400 validation_error`.
- Tenant ID continues to come only from tenant auth context.
