# TASK-0211: Platform Admin Labels + Cross-Surface UAT

## Outcome

Platform admin shell is localized EN/TH/JA, and a manual checklist proves all
three portals switch languages with persistence and fallback.

## Acceptance Criteria

1. Admin shell shows language selector; nav links and system health card localize.
2. Primary actions on Overview and Packages (or equivalent landing) use catalog
   strings.
3. Manual UAT checklist exists under `docs/sdlc/06-manual-tests/` covering:
   - EN/TH/JA switch on customer, tenant, admin
   - Reload persistence
   - Missing-key EN fallback (dev force or documented key)
   - AI reply locale unchanged when UI language changes
4. `npm run check` passes for `apps/platform-admin-web`.
5. No regression: login still works; RBAC routes unchanged.

## Verification

```bash
cd apps/customer-web && npm run check
cd apps/tenant-web && npm run check
cd apps/platform-admin-web && npm run check
```
