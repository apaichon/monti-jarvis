# TASK-0199: Project Topic Dimension Into Call-Center Analytics Facts

## Outcome

Completed conversation analytics facts include a normalized topic dimension
without introducing raw transcript, customer contact, or cross-tenant data.

## Acceptance Criteria

1. `call_center_usage_facts` schema/bootstrap includes `topic String` with
   fallback `unknown`.
2. Projection reads the topic from conversation metadata or call/session context
   and normalizes blank/invalid values to `unknown`.
3. `UpsertCallCenterFact` inserts topic without changing fact idempotency.
4. Existing and replayed facts do not double-count after the schema extension.
5. Tests cover explicit `general`, `billing`, `technical`, and missing topic.

## Notes

- Prefer adding topic to the existing fact table and query model; do not create
  a second analytics table.
- Keep `tenant_id` as the first query filter.

## Implementation

- Added `topic String DEFAULT 'unknown'` to ClickHouse bootstrap and migration.
- Added `topic` to `CallCenterUsageFact` insert projection and Sprint 32
  ClickHouse fixtures.
- Projection normalizes `summary.topic` and falls back invalid/missing values
  to `unknown`.
- Fact ID remains `ccf_<conversation_record_id>`, preserving replay
  idempotency.
