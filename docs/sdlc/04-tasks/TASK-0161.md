# TASK-0161: Artifact outputs (ON HOLD)

## Outcome

HTML, image/SVG, canvas JSON, link, report, and document outputs have explicit
MIME and filename metadata and are delivered through authenticated private URLs.

## Acceptance criteria

1. Every supported output maps to a stable artifact type and filename.
2. Generated HTML/SVG responses use private/no-store/nosniff headers and sandbox CSP.
3. Artifact size is bounded before persistence.
4. Customer UI previews HTML in a sandbox and renders other supported types safely.

## Verification

Artifact mapping tests pass and the customer build succeeds.
