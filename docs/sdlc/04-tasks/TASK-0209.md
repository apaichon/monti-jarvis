# TASK-0209: Customer Call Page + Directory Labels

## Outcome

Customer brand directory and call desk show EN/TH/JA labels for primary chrome
and expose the language selector.

## Acceptance Criteria

1. Tenant list (`/`) and call desk (`/t/{slug}`) include language selector.
2. Localized: Monti hero chrome, search/placeholder, brand card CTAs, call
   controls (start/end), topics, composer, audio settings, account/footer,
   Live · OK / system status wording, common errors.
3. Brand **names**, logos, and tenant-authored blurbs remain as server-provided
   (not machine-translated).
4. Switching language does not clear selected tenant or active call mid-session
   (labels update only).
5. `npm run check` passes for `apps/customer-web`.

## Notes

- Wire existing bilingual strings (e.g. S56 audio TH/EN) into the catalog.
- Prefer key names stable across apps when meaning matches (`lang_label`,
  `action_save`, `status_live`).
