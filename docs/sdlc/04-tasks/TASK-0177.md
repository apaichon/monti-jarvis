# TASK-0177: Environment, Secret Validation, Redaction, and Rotation Contract

## Outcome

Make production configuration explicit and fail closed for weak auth, unsafe
cookie/CORS behavior, missing read-role configuration, and secret exposure.

## Acceptance criteria

1. Production validates `JWT_SECRET`, cookie security, origins, writer/read
   database separation, and the RLS policy flag before serving traffic.
2. Startup, readiness, posture, and error logs redact secret values, embedded
   credentials, tokens, cookies, prompts, and request bodies.
3. Rotation guidance documents overlap, restart/reload behavior, revocation,
   and rollback without printing secret material.
4. Development bypasses are explicit, non-production-only, and reported as
   degraded posture.
5. Unit tests cover missing, weak, conflicting, and valid configurations.

## Implementation update

Production now fails closed for weak auth, insecure cookies, wildcard or
missing origins, disabled RLS, and missing capability pools. Startup and
infrastructure diagnostics redact common credential-bearing values; rotation
and rollback guidance is recorded in
`docs/sdlc/07-deployment/SPRINT-041-SECURITY-OPERATIONS.md`.
