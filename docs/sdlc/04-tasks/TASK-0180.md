# TASK-0180: Security Regression Suite and Two-Tenant UAT Evidence

## Outcome

Close the sprint with repeatable automated and manual evidence for the
security boundaries introduced by TASK-0176–TASK-0179.

## Acceptance criteria

1. The manual checklist covers browser migration/logout, unsafe configuration,
   read-role denial, secret redaction, and two-tenant denial.
2. Automated tests run without production credentials or real tenant data.
3. Evidence records commands, sanitized outputs, timestamps, and pass/fail
   results without including tokens, URLs with credentials, prompts, or PII.
4. Any deferred table/policy inventory is listed with owner and follow-up
   decision before release approval.

## Implementation update

Added `scripts/security-regression.sh` to run the Go tests, vet, and both
tenant/customer frontend checks and builds with sanitized evidence output.
The two-tenant database UAT remains the final operator-run step against a
disposable database.
