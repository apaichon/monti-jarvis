# TASK-0228: Align Platform Admin Leads List Contract and Rendering

## Outcome

Platform Admin consumes the server `items[]` field and renders returned leads
with an accurate server total.

## Acceptance criteria

1. `LeadsListResponse` defines `items: LeadListItem[]`.
2. The Leads page assigns normalized `items` to its rendered collection.
3. A missing total falls back to rendered item count.
4. Null collection values produce a safe empty state.
5. Existing filters and detail actions remain unchanged.
