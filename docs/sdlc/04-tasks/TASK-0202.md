# TASK-0202: Tenant List + Call Desk Logo Branding Revamp

## Done notes

Implemented in SPRINT-056 worktree.

## Outcome

Customer portal tenant list and call desk match mockup branding intent: large
Monti hero and large per-company logos (selected company card on desk).

## Acceptance criteria

1. `/` tenant list shows large Monti product mark and search chrome per mockup.
2. Each brand card shows large company logo (or monogram) + name + Call CTA.
3. `/t/{slug}` desk shows large Monti hero and selected-company logo card with
   brand name and change-brand control.
4. Switching brand updates company logo/name only (no cross-tenant leak).
5. Missing `logo_url` uses monogram fallback (first letter / initials).
6. Layout remains usable on desktop; mobile stacks without clipping logos.
