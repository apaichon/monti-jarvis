# TASK-0170: Product-web Shell and Marketing Pages

## Outcome

Create `apps/product-web` (SvelteKit static, base `/product`) with Monti dark
brand chrome, primary marketing routes, SEO metadata, and Go static serving
wired like tenant/platform portals.

## Acceptance criteria

1. Routes exist for Home, Product, Solutions, Resources, Pricing, About,
   Contact, and Demo entry under `/product/`.
2. Shared layout provides responsive nav/footer, Thai/English-ready content
   slots, accessible focus states, and logo/brand tokens.
3. `make product-web` builds static assets; server serves `/product/` and SPA
   fallback when `PRODUCT_WEB_DIR` is configured.
4. Demo CTA links to the existing no-auth customer surface with preserved safe
   attribution query params.
5. Register CTA links to `/tenant/register` with safe context only.

## Verification

```bash
make product-web
make build
curl -sI http://localhost:8091/product/ | head -5
git diff --check
```
