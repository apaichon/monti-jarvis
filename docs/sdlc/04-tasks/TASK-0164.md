# TASK-0164: Initialize AiaaS Package Defaults and Preserve Admin Edits

## Outcome

Seed the four AiaaS package defaults and a rules schema containing storage and
mobile-minute dimensions. Initialization must be idempotent and must never
overwrite values already changed by a platform administrator.

## Acceptance criteria

1. `aiaas-500`, `aiaas-1000`, `aiaas-1500`, and `aiaas-2000` are inserted when
   absent with the approved initialization values in THB.
2. The AiaaS rules schema validates avatar, KM, storage, concurrency, web
   minutes, mobile minutes, voice, and RAG fields.
3. Re-running initialization does not overwrite package name, price, status,
   or rules changed through platform package administration.
4. Existing platform package CRUD and entitlement assignment behavior remains
   compatible; changing a catalog row does not rewrite an existing rules
   snapshot.
5. Focused tests cover seed definitions and no-overwrite behavior.

## Verification

```bash
go test ./internal/store ./cmd/server -count=1
go test ./...
git diff --check
```

## Review — PASS

- Seed values match the approved S45 initialization catalog.
- `rules-v2` adds storage and mobile-minute dimensions without changing the
  existing `rules-v1` package contract.
- `ON CONFLICT (id) DO NOTHING` preserves platform-admin edits on restart.
- Existing package CRUD and entitlement assignment paths are unchanged.
- Focused and full Go test suites pass.
