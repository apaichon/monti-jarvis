# TASK-0224: Referral code validate and apply API

## Outcome

Tenant-scoped validate + apply with idempotent grant.

## Acceptance Criteria

1. `POST /api/tenant/referrals/redeem` validates and applies code.
2. Errors: not_found, expired, self, already_redeemed, ineligible, rate_limited.
3. Retry with same code is idempotent.
4. Auth tenant_admin only; no cross-tenant apply.
