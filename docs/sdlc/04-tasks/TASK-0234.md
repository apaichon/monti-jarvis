# TASK-0234: Redis Concurrent-Call Queue Admission Service

## Outcome

`internal/quota` can atomically admit a voice caller, enqueue a waiting caller,
or reject when non-concurrency quota/rate rules fail.

## Acceptance Criteria

1. Admission preserves existing rate, voice-enabled, monthly, daily, and
   per-call checks before queueing.
2. Below `max_concurrent_calls`, admission reserves the existing concurrent
   lease and returns `admitted`.
3. At limit, admission creates a FIFO Redis queue entry with position,
   estimated wait, expiry, and idempotency metadata.
4. Redis keys use DB 4 prefix `monti_jarvis:` and are safe for multiple app
   instances with a promotion lock.
5. Queue entry cancel/timeout cleanup is idempotent and tested.
