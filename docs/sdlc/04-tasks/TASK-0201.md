# TASK-0201: Tenant Dashboard Topic Breakdown UX and Verification

## Outcome

Tenant admins can scan topic demand on the existing Call Center dashboard and
filter statistics by topic for the selected date range.

## Acceptance Criteria

1. Dashboard shows a `By topic` section with count, duration, and share of total.
2. Dashboard includes an `All topics` / topic select filter wired to the
   statistics API.
3. Empty, `unknown`, mobile, and analytics-unavailable states are explicit.
4. Existing channel, avatar, quota, and KPI cards remain visible.
5. Verification seeds at least two topics plus missing-topic data and confirms
   tenant isolation.

## Notes

- Keep the dashboard operational, not marketing-style. The topic section should
  be dense and scannable beside channel/avatar breakdowns.

## Implementation

- Dashboard filter form includes an `All topics` topic selector.
- Summary includes selected topic context.
- Breakdown grid includes `By topic` rows with completed count, duration, and
  share of total completed conversations.
- Existing channel, avatar, quota, KPI, empty, and unavailable states remain.
