# TASK-0181: Shared-server Four-Portal Deployment

## Outcome

Deploy the existing customer, platform-admin, tenant, and product web builds
from Monti Jarvis on the Harvest-course server through one Monti image and one
same-origin Nginx/API entrypoint.

## Acceptance criteria

1. The deployment image builds and copies all four web outputs:
   `customer-web`, `platform-admin-web`, `tenant-web`, and `product-web`.
2. Compose sets the four web directories and enables product web explicitly.
3. The Monti-side deployment wrapper passes the requested checkout to the
   HarvestMax deployment script and supports status/help without mutating the
   checkout.
4. Shared-server verification checks `/healthz`, `/`, `/admin/`, `/tenant/`,
   and `/product/` through the configured public origin.
5. Deployment documentation names the path-based URLs, required environment
   values, Nginx ownership, and rollback procedure.

./scripts/deploy-shared-server.sh --help
