# TASK-0158: Provider adapter and job contract (ON HOLD)

## Outcome

Customer generation uses one bounded server-side Claude Messages adapter and a
unified provider/job contract. Codex, Antigravity, and Grok remain explicit
capability states until their runtimes are enabled.

## Acceptance criteria

1. Provider catalog exposes stable provider IDs, output types, and capability states.
2. Claude requests stay server-side, use bounded prompts/output, and redact provider errors.
3. Jobs expose queued, running, completed, and failed states with safe error codes.
4. Provider timeout/unavailable failures use at most one bounded retry.

## Verification

Automated adapter and server tests pass; external Claude UAT remains environment-dependent.
