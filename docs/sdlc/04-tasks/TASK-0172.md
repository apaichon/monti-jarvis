# TASK-0172: Public Pricing and Conversion Redirects

## Outcome

Expose a read-only public package catalog for product-web pricing and wire
CTA redirects that preserve only safe attribution context into demo, register,
and (post-auth) billing flows.

## Acceptance criteria

1. `GET /api/public/packages` returns active sellable packages with price,
   period, and public-safe feature/quota summary — no internal cost fields.
2. Pricing page never hard-codes commercial amounts; it renders API data.
3. Conversion helper preserves only allowlisted query keys
   (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`,
   `ref`, `package_id`, `lead_id`) and drops arbitrary redirect hosts.
4. Register and demo links open only Monti-relative paths
   (`/tenant/register`, `/`, `/product/contact`, `/product/demo`).
5. Selecting a package from public pricing does not create entitlements;
   checkout remains authenticated tenant billing.

## Verification

```bash
go test ./cmd/server ./internal/store -count=1
# GET /api/public/packages returns active catalog
# CTA builder rejects external redirect targets
git diff --check
```
