# TASK-0197: Isolation Verification + UAT

## Outcome

Prove pick-A vs pick-B isolation, deep-link behavior, and empty-directory
handling. Ship a manual UAT checklist under `docs/sdlc/06-manual-tests/`.

## Acceptance criteria

1. Two listed tenants A and B: selecting A shows only A workforce; B only B.
2. After a short chat on A, switching to B never shows A transcript or A agents.
3. Unlisted / pending tenants never appear in the public list.
4. Deep link `/t/{slug}` and legacy `?tenant_id=` both reach the correct desk.
5. Empty directory (no listed brands) shows empty state, not a hard crash.
6. Manual test doc: `docs/sdlc/06-manual-tests/SPRINT-054-customer-tenant-list-manual.md`
   with pass/fail boxes covering AC 1–5.
7. Automated tests cover at least directory filter + resolve 404 + one portal
   smoke path if feasible (Go store/handler tests minimum).
