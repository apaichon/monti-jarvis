# TASK-0212: Conversation Shell Layout and Responsive Structure

## Outcome

Customer-web has the new call conversation shell for desktop and mobile, with a
left context rail, central avatar/conversation stage, right context panels, and a
single-column mobile order.

## Done Notes

Implemented the Sprint 59 customer-web shell in `CustomerDesk.svelte`: the page
now renders a three-area desktop layout and a mobile-first stacked layout with a
central conversation hero.

## Acceptance Criteria

1. `CustomerDesk` renders the new desktop structure without changing call or
   tenant-selection behavior.
2. Mobile layout stacks header, avatar stage, controls, transcript, composer,
   and context rows without horizontal scroll.
3. Avatar stage remains prominent during active calls and does not collapse into
   only a small rail item.
4. Layout uses stable dimensions for avatar, controls, transcript, and composer
   so active states do not shift the page.
5. Existing S56 audio-device entry points and S58 labels remain reachable.

## Notes

- Prefer existing customer-web components and state.
- Keep backend/API untouched.
