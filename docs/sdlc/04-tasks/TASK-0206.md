# TASK-0206: Add Open Graph and Twitter Social Preview Metadata

## Outcome

Root-domain HTML publishes rich-preview metadata so Facebook and other link
preview crawlers show the Monti image, title, and description.

## Done Notes

Added Open Graph and Twitter metadata to customer-web and product-web app
shells. Customer root metadata uses `https://monti.devclub.dev/`; product
metadata uses `https://monti.devclub.dev/product/`.

## Acceptance Criteria

1. Root page source includes `og:title`, `og:description`, `og:image`,
   `og:image:alt`, `og:url`, `og:type`, and `og:site_name`.
2. Root page source includes `twitter:card`, `twitter:title`,
   `twitter:description`, `twitter:image`, and `twitter:image:alt`.
3. Production metadata uses absolute URLs for `og:url`, `og:image`, and
   `twitter:image`.
4. Development/local metadata remains safe and does not hard-fail when
   production origin config is missing.
5. Metadata description matches Monti AI Call Center positioning.

## Implementation Notes

- Use existing Svelte/Vite/SvelteKit head metadata pattern for the target root
  app.
- Prefer config/env origin only for the absolute production base URL; avoid
  hardcoding localhost into deployed HTML.
