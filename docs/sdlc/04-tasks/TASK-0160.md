# TASK-0160: Jobs and artifacts (ON HOLD)

## Outcome

Tenant/customer-owned jobs and artifact metadata persist in Postgres while
artifact bytes are stored under the tenant/customer MinIO prefix.

## Acceptance criteria

1. Job creation is idempotent by tenant, customer, and idempotency key.
2. Prompt, artifact, timeout, and retry bounds are enforced server-side.
3. Artifact metadata includes MIME, filename, size, and SHA-256.
4. Job and artifact reads enforce both tenant and customer ownership.

## Verification

Migration, store methods, bounded worker, and object-prefix code are present;
Postgres/MinIO integration requires Docker-backed UAT.
