# TASK-0231: Stripe Checkout Adapter and Tenant Checkout Routing

## Goal

Add a Stripe provider adapter and route tenant Shared Cloud checkout through it
when `stripe` is the active provider.

## Acceptance Criteria

1. `internal/payment/stripe` can create a Stripe Checkout Session for an
   existing `payment_orders` row.
2. `POST /api/tenant/checkout` stores the order with `provider=stripe`,
   provider session/payment references, and returns Stripe `payment_url`.
3. Server-calculated package amount, currency, billing interval, tax snapshot,
   tenant ID, package ID, and order number are sent as Stripe metadata.
4. Dedicated VM quote-only packages still return `PACKAGE_REQUIRES_QUOTE`.
5. `mock` and `chillpay` checkout behavior remains unchanged.

## Build Notes

- Added `internal/payment/stripe` Checkout Session client and explicit tenant checkout routing for `mock`, `chillpay`, and `stripe`.
- Stripe orders store provider session/payment refs and return the hosted payment URL.
