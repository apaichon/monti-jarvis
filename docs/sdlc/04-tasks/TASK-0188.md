# TASK-0188: Tenant Setting + Store (Auto-Register on Conversation OTP)

## Outcome

Tenant customer-auth settings include `auto_register_on_conversation_otp`
(default false), readable/writable by tenant admin and respected by customer
OTP paths.

## Acceptance criteria

1. Schema/migration adds boolean column (default false) on
   `tenant_customer_auth_settings`.
2. GET/PUT tenant customer-auth settings expose the new field.
3. Tenant Settings UI toggle with clear copy; save persists.
4. When false, conversation auto-register path is disabled server-side.
5. Unit tests cover default and update.
