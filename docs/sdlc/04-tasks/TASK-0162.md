# TASK-0162: Workspace UI (ON HOLD)

## Outcome

Authenticated customers can connect Claude, select an output, submit a bounded
prompt, observe progress, inspect history, and preview generated artifacts.

## Acceptance criteria

1. Anonymous users see a sign-in requirement and cannot submit jobs.
2. Provider capability and masked credential states are visible.
3. Queued/running/completed/failed states and safe error messages are visible.
4. Artifact preview uses the authenticated API URL and a sandboxed HTML iframe.

## Verification

Customer `npm run check` and `npm run build` pass.
