# TASK-0190: App Version on UI

## Outcome

Surfaces show the same app version as `VERSION` / release tag (e.g. `v2.24.0`).

## Acceptance criteria

1. Server exposes version (extend `/healthz` and/or `GET /api/version`) from
   embedded `VERSION` string.
2. Tenant console shows version (sidebar footer or settings).
3. Platform admin shows version.
4. Customer portal shows version in a small footer (optional but preferred).
5. Label matches file contents of `VERSION` for the build (prefix `v` allowed
   if canonicalized consistently).

## Verification

```bash
curl -sS localhost:8091/healthz | jq .version
# UI footer/sidebar shows same value
```
