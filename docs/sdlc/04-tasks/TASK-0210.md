# TASK-0210: Tenant Portal UI Labels

## Outcome

Tenant console shell and primary navigation/actions use the selected display
language (EN/TH/JA).

## Acceptance Criteria

1. Language selector is available in tenant shell (sidebar foot or top bar).
2. Nav group labels and nav links localize (Operations, Knowledge, Commerce,
   Channels, Directory, Growth, Settings and link titles).
3. Common chrome localizes: loading session, current plan card labels, sign out,
   primary Save/Cancel/Delete/Create actions, empty states on Overview +
   Settings at minimum.
4. Settings page clearly separates **Display language** (UI) from **Workspace /
   AI reply locale** (S16) with distinct copy.
5. `npm run check` passes for `apps/tenant-web`.

## Notes

- Secondary dense tables may keep some EN cells if key inventory incomplete —
  never blank; fall back to EN.
- Do not translate tenant-authored names (avatar names, package names from API).
